## Описание
Программа строит таблицу вероятности безотказной работы реле с двумя парами контактов P = f(t) по формулам (1) и (2) из задания. Значения t идут с изменяющимся шагом. Первый участок (t = 200–1000 ч, шаг 200 ч) обрабатывает цикл do while, второй участок (t = 2000–5000 ч, шаг 1000 ч) обрабатывает цикл while. Точка перехода 1000 ч входит в первый участок и во втором не повторяется. В таблице получается 9 строк.

## Входные данные
Вводятся с клавиатуры, дробные числа через точку:
- λ1 – интенсивность отказа одной пары контактов, 1/ч (в варианте 0.009);
- λ2 – интенсивность отказа одной пары после отказа другой, 1/ч (в варианте 0.00068);
- φ – вероятность отказа типа замыкания (в варианте 0.73).

Значения t и шаги заданы в программе по условию варианта.

## Выходные данные
Одна общая таблица с заголовком и единицами измерения:
- t (h) – время работы реле;
- P (%) – вероятность безотказной работы.

## Как запустить
Открыть проект в Visual Studio (Console App, C++17), собрать и запустить без отладки: Ctrl+F5. Ввести три значения через пробел или по одному на строке.
